# n8n-free-templates

Selected n8n workflow templates imported from [wassupjay/n8n-free-templates](https://github.com/wassupjay/n8n-free-templates).

## Categories

| Folder | Workflows |
|--------|-----------|
| AI_ML | Auto-tag blogs, sentiment analysis, image captioning, resume screening, and more |
| Agriculture | Crop yield predictor, irrigation optimizer, pest alerts, soil analysis, and more |
| Creative_Content | YouTube transcript to blog post |
| Education | Quiz auto-grader, daily student motivation |
| IoT | MQTT monitor, sensor fault detector, smart home energy saver, and more |
| Media | News summarizer, podcast notes, ad campaign alerts, and more |
| Social_Media | Auto-post to LinkedIn/Twitter, TikTok replies, YouTube summarizer, and more |

## Usage

1. Open n8n → Settings → Import Workflows
2. Select any .json file from the folders above
3. Add your credentials to each node
4. Save & Activate
