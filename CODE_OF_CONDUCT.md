# Code of Conduct

## Our Standards

We are committed to a welcoming, harassment-free environment for all contributors.

Examples of expected behavior:

- respectful and constructive feedback
- openness to different viewpoints
- responsible disclosure of mistakes and security concerns

Unacceptable behavior includes harassment, discrimination, doxxing, threats, and disruptive conduct.

## Enforcement

Project maintainers may remove, edit, or reject comments/issues/PRs that violate this code of conduct.

## Reporting

Report conduct concerns through private maintainer contact or security channels listed in `SECURITY.md` when appropriate.

## Scope

This code applies to project spaces (issues, PRs, discussions) and public community interactions tied to this repository.
